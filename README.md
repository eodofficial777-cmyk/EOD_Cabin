# 荒中小屋 線上版

## 檔案在做什麼

| 檔案 | 用途 |
|---|---|
| `public/index.html` | 玩家看到的網頁：大廳、遊戲畫面、聊天室、匯出噗浪格式 |
| `public/engine.js` | 遊戲規則引擎。**規則和平衡數字都改這個檔案** |
| `public/firebase-config.js` | 你的 Firebase 專案設定（要自己填） |
| `functions/index.js` | 伺服器：收玩家的操作、跑引擎、把每個人能看的畫面寫回去 |
| `functions/engine.js` | 引擎的複本。部署時會自動從 `public/engine.js` 複製過來，不用手動改 |
| `database.rules.json` | 安全規則：誰能讀寫什麼 |
| `firebase.json`、`.firebaserc` | 部署設定 |

## 第一次設定

1. **Realtime Database**：Firebase 主控台 → 建構 → Realtime Database → 建立資料庫。位置選 `asia-southeast1`（新加坡），以鎖定模式開始。
   - 如果你選了別的位置，要把 `functions/index.js` 最上面的 `REGION` 改成一樣的。
2. **匿名登入**：Authentication → 登入方式 → 啟用「匿名」。
3. **升級 Blaze**：Cloud Functions 需要 Blaze 方案。升級後到 Google Cloud 的「預算與快訊」設一個低額提醒（例如 1 美元）。
4. **網頁設定**：專案設定 → 一般 → 新增網頁應用程式，把設定值貼進 `public/firebase-config.js`。`databaseURL` 一定要填。
5. **專案 ID**：把 `.firebaserc` 裡的「填入你的-firebase-專案-id」換成你的專案 ID。
6. **存檔密鑰**：第一次部署前，在終端機執行 `firebase functions:secrets:set SAVE_KEY`，輸入一長串隨便打的英數字。存檔會用它加密。**設定之後不要改**，改了舊存檔就讀不回來。

## 部署

需要一個終端機，Firebase Studio 或 GitHub Codespaces 都可以：

```bash
npm install -g firebase-tools
firebase login --no-localhost
cd functions && npm install && cd ..
firebase deploy
```

部署完的網址是 `https://你的專案ID.web.app`。

之後只改了網頁或規則，可以只部署那一部分：

```bash
firebase deploy --only hosting      # 只改了 public/ 裡的網頁
firebase deploy --only database     # 只改了安全規則
firebase deploy --only functions    # 改了 engine.js 或 functions/
```

**改了 `engine.js` 一定要部署 functions 和 hosting 兩邊**，不然前端和伺服器的規則會不一樣。

想放 GitHub Pages 也可以：把 `public/` 裡的檔案放上去就好，Functions 和規則還是用 `firebase deploy` 部署。

## 怎麼測試

**不用 Firebase 也能先玩**：`firebase-config.js` 還沒填，或網址加上 `?local=1`，就會進入測試模式。整局在同一台裝置上跑，畫面上方可以切換每個人的視角，用來試規則很方便。

線上測試至少要 4 個玩家。用不同的瀏覽器或裝置開（一般視窗、無痕視窗、手機……），每個都會是不同的匿名玩家。

## 規則摘要

- **人數**：有身份模式 5–8 人（8 人時兩隻怪物），無身份合作模式 3–8 人。
- **白天**：輪流行動，每人 2 點行動點。
  - 點燈：用燭台點亮所在房間或相鄰的一格（1 點，被怪物熄過的房間 2 點）。沒有燭台可以用火柴。
  - 探索：走進點亮的黑暗，擲 1D20。1–2 災獸，3–5 特殊事件，達到門檻是封印房間（5 人以下 17 以上、6 人 18 以上、7 人以上 19 以上），其餘是一般房間。連續沒遇到封印房會保底（5 人以下 5 次、6 人 6 次、7 人以上 8 次）。
  - 搜索：亮著的房間每次雷雨之間只能搜一次。燭台儲藏室必定找到燭台；封印房第一次搜索必定找回「屬於自己的裝備」。
  - 鑰匙（只有普通人和巫師有）：每次雷雨之間可以鎖一間房（不能鎖自己所在的那間），不花行動點。鎖上的房間在下次雷雨結束前誰都不能進出。把可疑的人鎖在房裡，他雷雨時就只能對同一間出手。
  - 摸黑：沒有燭台也能走進暗房、在暗房裡摸黑搜索，會擲骰遇到事件：可能受傷、被嚇到，也比較容易摸到燭台。
  - 攻擊：理智崩潰、身份曝光的怪物跟你同一間房時可以攻擊（1 點）。命中造成 1D6 傷害，累積 10 點就壓制牠（下次雷雨不能作祟、下回合不能行動）；沒命中會被抓傷。屋內造成的傷害會讓中庭的怪物 HP 變低。
- **雷雨**：每 2 輪一次，同時行動。
  - 怪物三選一：熄燈、偷落單者的燭台、作祟某人。理智崩潰後陷入狂暴：熄燈會連相鄰一盞一起熄、偷燭台不用等對方落單、作祟巫師更容易讓她墮落、作祟普通人還會扣理智。
  - 巫師二選一：用燭火看見一個人的身份（整局一次，看完燭台燃盡）；或張開守護結界保護一個人（整局 2 次，不能連續守同一人、不能守自己），被守護的人不會被偷燭台、不會被作祟，他所在的房間也不會被熄燈。結界擋下作祟時巫師會知道，大家只看到「有一道結界擋下了什麼」。
  - 魔人（墮落的巫師）：可以熄燈。
  - 怪物熄燈時，待在那間房裡的人擲 1D6 遇到黑暗事件；擲到 6 會瞥見熄燈者，得到「A 或 B 其中一人」的線索。
  - 雷雨的風會吹熄一盞燈，怪物的假燈也會在這時消失。雷雨過後才檢查封印。
- **封印需要的同類房間**：5 人以下 1 間、6 人以上 2 間。
- **燭台的來源**（有身份模式）：墓園的搜索表 1/6、摸黑搜索 1/6、燭台儲藏室第一次搜索必定有。其他地方大多只會找到火柴。無身份合作模式沿用比較寬鬆的機率：一般、作物、墓園搜索各 1/6，摸黑搜索 2/6，摸黑移動 1/6，燭台儲藏室每次搜索都有。
- **怪物獲勝**：所有人類陣營都沒有燭台，或撐過指定次數的雷雨（次數依人數而定，畫面上方有顯示）。
- **中庭決戰**：三道封印解開後開始。身份全部公開，怪物玩家親自操控頭目，魔人和第二隻怪物當爪牙。
  - 頭目 HP 50，每個被偷的燭台 +5，人類每多於 3 人 +27。防禦每回合 1D10+8。
  - 開戰時人類做理智檢定，成功扣 1D3，失敗扣 1D20。

所有數值都在 `engine.js` 最上面的 `RULES`。

## 角色頭像

- 每個人可以放三張頭像：**怪物化**（開場）、**半怪物化**（同時點亮 5 間房後）、**原形**（同時點亮 10 間房後）。對應原版「點亮的區域越多，身上不屬於自己的特徵越少」，人類和怪物陣營都一樣。
- 可以只放一張或兩張，缺的階段會自動用最接近的那張。
- 恢復等級上升時，紀錄會寫一行「特徵開始消退……」，所有人的頭像同時換。
- 理智崩潰而身份曝光的怪物，會變回怪物化的樣子；中庭決戰時，怪物陣營也會以怪物化的樣子出場。
- 上傳的圖片會在瀏覽器裡裁成正方形、縮到 128×128，每張通常 5–15 KB，直接存在資料庫裡，不需要另外開檔案空間。也可以貼 https:// 開頭的圖片網址。
- 頭像會記在各自的瀏覽器裡，下次進房自動帶入。

## 噗浪表符

- 首頁和大廳有「噗浪表符代碼」：在噗浪發噗框點一下自訂表符，把框裡多出來的文字整段複製貼上。
- 一樣分怪物化、半怪物化、原形三階段，只填一個就一直用那個。
- 匯出噗浪格式時，角色台詞前面會自動加上當下階段的表符代碼。匯出畫面可以勾掉這個功能。
- 代碼會算進每則噗文的 300 字。

## 存檔與紀錄

- 遊戲畫面上方的「存檔」：
  - **下載紀錄（.txt）**：劇情、角色 RP、玩家討論，所有人都能下載。遊戲結束後也會一起包含觀眾席和狼人頻道。
  - **下載存檔（.lhsave）**：只有玩家能下載。每次有人行動，伺服器就自動更新一份。存檔是加密的，打開也看不到任何人的身份。
- **讀檔**：房主開新房間，原本的玩家用一模一樣的名字加入、人數相同，房主在大廳按「讀取存檔」。遊戲會從存檔當下的進度繼續，倒數會先給一分鐘。
- 測試模式也能存檔、讀檔，但測試模式的存檔沒有加密，也不能拿去線上版讀。

## 自動清理

- 伺服器每 6 小時（台灣時間）自動清理一次：聊天訊息超過 7 天就刪除，包括大廳聊天、劇情 RP、玩家討論、觀眾席、狼人頻道。
- 房間和遊戲資料不會自動刪除。
- 時間可以在 `functions/index.js` 調整：`CHAT_TTL_HOURS` 是聊天保留的小時數；`ROOM_TTL_DAYS` 設成大於 0 的天數，就會刪掉那麼多天沒有動靜的房間。
- 想留紀錄的話，記得在清理前用「存檔 → 下載紀錄」。

## 流量估算

- 資料分成三塊下載：公開畫面（每次約 3 KB）、自己的私人資料（不到 1 KB）、紀錄（只下載新增的那幾行）。
- 6 人局一場大約 160 次結算，每位玩家或觀眾大約下載 0.5 MB。伺服器每次結算還會讀寫一次完整狀態（約 30 KB），一場約 5 MB。
- 合計一場 6 人、加 10 位觀眾，大約 13 MB。Firebase 免費額度每月 10 GB 下載，約可跑 700 場以上。正式開放前請到 Firebase 官網確認最新的計費方式。

## 事件卡與擲骰動畫

- 有人探索、搜索、摸黑前進、攻擊時，地圖上方會跳出事件卡：先播放擲骰動畫（全部骰子加起來不超過約 2.5 秒），再顯示結果。
- 「下回合不能行動」「受到傷害」「理智下降」這類會影響角色的結果會用紅字標出來。
- 事件卡會一直留著，直到按「知道了」或下一個事件出現。系統設定「減少動態效果」的裝置會直接顯示結果。

## 自動暫停（線上人數不足）

- 限時模式下，如果線上的玩家少於 2 人，遊戲會自動暫停，有第二位玩家回來就自動繼續。避免只剩一個人開著網頁時，倒數一直把其他人的回合跳掉。
- 所有人都離線時，伺服器不會自己推進遊戲；房間只是靜靜存在資料庫裡，不會產生流量。

## 不限時模式（預設）

- 新房間預設是「不限時」：沒有倒數，大家慢慢來，適合邊 RP 邊玩。房主在大廳可以改成快速、標準或 RP 慢慢來（有倒數）。
- 有人離開或卡住時，房主右側會出現「房主操作」：白天可以「跳過某人的回合」，雷雨、決戰、看身份時可以「不等了，直接結算」。還沒行動的人算成不行動，決戰時人類自動攻擊。
- 這個推進按鈕在限時模式也能用，不必等倒數跑完。只有房主能用，伺服器會檢查。
- **暫停**：限時模式下，房主可以按「暫停」。倒數會凍結在當下剩的秒數，暫停期間大家都不能行動，但聊天照常；按「繼續」後從剩下的秒數接著倒數（至少留 5 秒）。

## 遊戲指南

- 進房間時會自動打開「遊戲指南」，分成目標、流程、操作、圖例與介面四頁。可以勾選「進房間時不要自動打開」。
- 大廳右上的「遊戲指南」、遊戲畫面上方的「指南」隨時都能再打開。
- 指南的內容寫在 `index.html` 的 `guideHtml()` 裡，數字會自動帶入 `RULES`。

## 一人多角（副角色）

- 房主在大廳勾選「允許玩家帶副角色」後，每位玩家可以在大廳多新增一個副角色（名字不能跟別人重複）。
- 副角色固定是普通人，不會抽到怪物或巫師，所以同一個人操作兩個角色也不會造成身份外流。
- 有身份模式至少要有「怪物數＋2」位主角色（5–7 人時 3 位、8 人時 4 位），不夠的話不能開局。
- 遊戲中畫面上方會出現「操作角色」切換列，另一個角色需要行動時會標示「要行動了」。聊天時，用目前選擇的角色發言。
- 在大廳時，可以按「和主角色互換」交換主、副角色的名字、頭像和表符，也可以「移除副角色」。
- 一局結束後，房主可以按「回到大廳」：大家能調整角色、新增或移除副角色、讓新玩家加入，再重新開始。上一局的劇情聊天會在新局開始時清掉。
- 測試模式可以把任何座位設為副角色，確認身份分配。

## 換裝置（重新登入碼）

- 同一個瀏覽器關掉再開、重新整理、斷線，都會自動回到自己的座位，不需要登入碼。
- 開局時，每位主角色會拿到一組 6 碼的「重新登入碼」，在右側狀態表按「顯示」就看得到。副角色跟主角色共用同一組。
- 換裝置時：在首頁填房間代碼、角色名字（跟遊戲裡一模一樣），展開「換了裝置？」輸入登入碼。副角色會跟著主角色一起回來。
- 驗證在伺服器上做，登入碼只有本人看得到。同一個角色錯 8 次會被鎖住。
- 接回之後，舊裝置會自動失去這個座位並回到首頁，不會有兩台裝置同時操作同一個角色。聊天紀錄、頭像、表符、房主身份都會一起轉過來。
- 讀檔或開新局時，登入碼會重新產生。

## 觀戰

- 首頁輸入房間代碼後按「觀戰」，不佔玩家名額，遊戲開始後也能進來，最多 30 人。
- 觀眾只看得到公開資訊（地圖、紀錄、劇情、玩家討論），看不到任何人的身份和燭台。
- 觀眾不能在劇情或玩家討論發言，只能在「觀眾席」聊天。觀眾席在遊戲結束前玩家看不到，避免有人報牌。
- 還在大廳時，觀眾可以按「我要上場」改當玩家（玩家未滿 8 人時）。
- 測試模式的視角選單裡有「觀眾視角」，可以先看看觀眾看到什麼。

## 規則怎麼保護

- 玩家只能寫入 `rooms/{代碼}/intents`。伺服器會把動作的發送者強制改成本人，也只接受白名單裡的動作。
- 完整的遊戲狀態在 `game/{代碼}/state`，沒有任何玩家能讀。每個人只讀得到自己那份 `views/{自己的uid}`。
- 狼人頻道由安全規則對照伺服器的身份表，非怪物讀不到也寫不進去。
- 倒數由伺服器時間判斷，改自己電腦的時間沒有用。

## 目前的限制

- 房主在大廳離開的話，房間就沒人能按開始，要重開一間。
- 舊房間不會自動清掉，資料多了可以到主控台手動刪 `rooms` 和 `game`。
- 手機上打字時如果剛好有新訊息進來，畫面會重繪，輸入框會保留內容，但鍵盤可能閃一下。
